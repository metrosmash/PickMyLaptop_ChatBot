# 💬 PickMyLaptop_Chatbot

AN App that uses an AI Agent to help users pick their best choice of laptops.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://chatbot-uc6zpm9iv3.streamlit.app/)
### How to install on your machine 
1. Download and Install git (if not installed) [here]( https://git-scm.com/download/win)

2. Open command Prompt 
- press Win + R, type cmd, and press Enter
   - or if you have a specific folder for your projects 
   - navigate to the folder and then press Shift + right-click your mouse
   - click open terminal 

3. git clone the repository 
```commandline
git clone https://github.com/metrosmash/PickMyLaptop_ChatBot.git
```
### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
